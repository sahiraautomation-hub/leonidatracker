GTA 6 Cheats for PS5: Every Found Code with DualSense Controls

CheatsBy LeonidaTracker Editorial·Updated 2026-11-22·2 min read

On PlayStation 5, GTA 6 cheats go through the phone and the shoulder buttons. This page shows every found code with the PS5 input already filled in, so you can follow along with a DualSense in hand.

PS5 input

  • Press Up on the D-pad to take out the phone.
  • Hold L1 and press R1.
  • Still holding, enter the D-pad code.
  • Watch for the confirmation message.

The DualSense touchpad and face buttons are not used. Every code is directional input only.

Frequently asked questions

Do I hold L1 for the whole code on PS5?

Yes. Hold L1, press R1, and keep holding while you enter the D-pad sequence.

Do PS5 cheats disable trophies?

Yes, for the session in which you use them.

Are the codes the same as Xbox?

The D-pad sequences are identical. Only the shoulder buttons differ.
