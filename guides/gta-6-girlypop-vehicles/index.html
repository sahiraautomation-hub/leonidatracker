GTA 6 Girlypop Vehicles: All 16 and the Neon Jungle Cheat

CollectiblesBy LeonidaTracker Editorial·Updated 2026-11-22·2 min read

Girlypop Vehicles are a discovery collectible in GTA 6. Find all 16 and you unlock the Neon Jungle screen filter cheat.

Why hunt them

Neon Jungle is one of 16 screen filter cheats. Its requirement is simple: discover all 16 Girlypop Vehicles.

Logging finds

Mark each discovery on the counter in the Tracker the moment you spot it. Vehicle discoveries also show in the Vehicles card of the Progress menu, which helps confirm a find.

Other vehicle discoveries

The Progress menu also drives three spawn cheats: the Interstate Ambulance, MTL Pumper and HVY Bulldozer unlock when you discover them. The Pumper and Bulldozer codes are already known.

Cheat-by-cheat notes

Neon Jungle

Applies the Neon Jungle screen filter. To unlock it, discover all 16 Girlypop Vehicles. The code has not been confirmed yet. Work on the challenge now so it is ready when the code is published. Log each Girlypop find the moment you spot it.

MTL Pumper

Spawns an MTL Pumper. To unlock it, discover the MTL Pumper in the Progress menu. The input is 8 presses: Left, Up, Right, Down, Left, Right, Right, Up. It shares its first 5 or more inputs with Maibatsu Boomazoom, HVY Bulldozer, so slow down at the end. Differs from HVY Bulldozer only on the last input (Up).

HVY Bulldozer

Spawns an HVY Bulldozer. To unlock it, discover the HVY Bulldozer in the Progress menu. The input is 8 presses: Left, Up, Right, Down, Left, Right, Right, Down. It shares its first 5 or more inputs with Maibatsu Boomazoom, MTL Pumper, so slow down at the end. Ends with Down, where the MTL Pumper ends with Up.

Interstate Ambulance

Spawns an Interstate Ambulance. To unlock it, discover it in the Progress menu. The code has not been confirmed yet. Work on the challenge now so it is ready when the code is published. Progress-menu vehicles unlock once you have found the vehicle in the world.
