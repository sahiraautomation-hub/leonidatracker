How to Save in GTA 6: Manual Saves, Autosave and Slots

BasicsBy LeonidaTracker Editorial·Updated 2026-11-22·2 min read

Saving matters more in GTA 6 than in earlier games, for two reasons. Autosave is limited, and there is no way to replay a finished mission. A good manual save habit is the only safety net you have.

How to save manually

  1. Press Options on PS5 or Menu on Xbox to pause.
  2. Go to the Game tab.
  3. Choose Save Game and pick a slot.

You cannot save in the middle of a mission. Save before you start one, or after it ends.

How autosave works

Autosave runs when a mission ends. It does not run constantly while you roam, so free-roam progress since your last mission, such as collectibles, purchases and money earned, is not protected until you save by hand.

The Prologue

Manual saving is reported to be unavailable during the Prologue. Plan to play through it in one sitting, then make your first save as soon as the option appears.

No mission replay

GTA 6 has no mission replay and no New Game Plus. If you want to see a mission again, or you miss something that cannot be done later, the only way back is an older save. That makes a save at the start of each chapter worth the few seconds it takes.

A save routine that works

  • One slot per chapter. Save at the start of each chapter and never overwrite those slots. The game is reported to offer 15 manual slots, which is plenty.
  • One rolling slot. Overwrite this one as you play.
  • One slot before the final mission.
  • One cheat slot. Using a cheat disables saving and trophies for the session, so load a separate save when you want to experiment. See cheats, trophies and saving.

When a save matters most

  • Before Tourist Trap, the Chapter 1 point of no return. See missable content.
  • Before any rampage that could damage your Criminal Profile.
  • After banking a big score, so the money is locked in.
  • Before attempting a six-star survival run or other risky challenge.

Frequently asked questions

How do you save in GTA 6?

Pause, open the Game tab and choose Save Game. You cannot save during a mission.

Does GTA 6 autosave?

Yes, but only when a mission ends. Free-roam progress is not autosaved, so save manually.

Can you replay missions in GTA 6?

No. There is no mission replay, so keep a manual save at the start of each chapter.
