How to enter the Lapwing Mallard code

  1. Press Up on the D-pad during gameplay to take out the phone.
  2. On PS5, hold L1 and press R1. On Xbox Series X|S, hold LB and press RB.
  3. Keep holding and press: Left, Up, Right, Down, Left, Up, Up, Up.
  4. Wait for the on-screen confirmation.

Ends Up, Up, Up. First step toward the Progen Emerus.

How to unlock Lapwing Mallard

Complete five vehicle challenges. Like every cheat in GTA 6, it also stays locked until the main story is finished.

Keep count on the Vehicle challenges completed counter in the Tracker. The target is 5.

Codes that look almost the same

Lapwing Mallard belongs to a family of codes that open the same way. Entering the wrong ending triggers a different cheat, or nothing at all.

  • Interstate Ambulance shares the first 5 presses. It splits at press 6: Up for Lapwing Mallard, Right for Interstate Ambulance.
  • Maibatsu Boomazoom shares the first 5 presses. It splits at press 6: Up for Lapwing Mallard, Left for Maibatsu Boomazoom.
  • MTL Pumper shares the first 5 presses. It splits at press 6: Up for Lapwing Mallard, Right for MTL Pumper.
  • HVY Bulldozer shares the first 5 presses. It splits at press 6: Up for Lapwing Mallard, Right for HVY Bulldozer.
  • Speeder 700 GT shares the first 5 presses. It splits at press 6: Up for Lapwing Mallard, Down for Speeder 700 GT.

Learn the shared opening once, then focus on the ending. The code patterns guide covers every family.

Before you use it

Using any cheat disables saving, trophies and achievements for that session. Make a manual save in a separate slot first, and reload your clean save when you are done. Details in cheats, trophies and saving. If the code does nothing, work through the seven common causes.

Frequently asked questions

What is the Lapwing Mallard cheat code in GTA 6?

Take out the phone, hold L1 and press R1 on PS5 (LB and RB on Xbox), then enter Left, Up, Right, Down, Left, Up, Up, Up.

How do I unlock Lapwing Mallard?

Complete five vehicle challenges. You also need to have finished the main story.

Is the Lapwing Mallard code the same on PS5 and Xbox?

Yes. The D-pad sequence is identical. Only the shoulder buttons differ: L1 and R1 on PS5, LB and RB on Xbox Series X|S.
