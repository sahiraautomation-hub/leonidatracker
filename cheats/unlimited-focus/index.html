How to enter the Unlimited Focus code

  1. Press Up on the D-pad during gameplay to take out the phone.
  2. On PS5, hold L1 and press R1. On Xbox Series X|S, hold LB and press RB.
  3. Keep holding and press: Down, Up, Up, Down, Up, Down, Up, Down, Up, Right.
  4. Wait for the on-screen confirmation.

Pairs well with the shooting-range medal grind if you want to practise aim without a meter running out.

How to unlock Unlimited Focus

Unlimited Focus is one of only four cheats that need nothing except the main story. Once the credits roll it appears in the Cheats list of the Progress menu, ready to use.

Before you use it

Using any cheat disables saving, trophies and achievements for that session. Make a manual save in a separate slot first, and reload your clean save when you are done. Details in cheats, trophies and saving. If the code does nothing, work through the seven common causes.

Frequently asked questions

What is the Unlimited Focus cheat code in GTA 6?

Take out the phone, hold L1 and press R1 on PS5 (LB and RB on Xbox), then enter Down, Up, Up, Down, Up, Down, Up, Down, Up, Right.

How do I unlock Unlimited Focus?

Finish the main story. No extra challenge is needed.

Is the Unlimited Focus code the same on PS5 and Xbox?

Yes. The D-pad sequence is identical. Only the shoulder buttons differ: L1 and R1 on PS5, LB and RB on Xbox Series X|S.
